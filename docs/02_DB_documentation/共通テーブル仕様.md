## 命名規則
### テーブル名・カラム名共通
- 大文字を利用しないこと
- 複数単語の連携はスネークケースで行うこと
- 英語表記を使い、略名は利用しないこと

### テーブル名
- 各単語が複数形であること
  - 例: `users_categories`

### カラム名
- 単数形であること
- 他テーブルの主キーと join するカラムは テーブル名(単数系)_id であること
  - 例: `user_id`

## 共通カラム
- `created_at`
  - 作成日時
- `updated_at`
  - 更新日時
- `created_by`
  - 作成者
- `updated_by`
  - 更新者
